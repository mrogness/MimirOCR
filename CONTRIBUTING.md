# Contributing to MimirOCR

Start with the [contributor guide](docs/contributing.md) for setup, tests, and PR
expectations. The [OCR walkthrough](docs/tutorials/first-ocr-run.md) connects the
desktop workflow to its implementation. See [troubleshooting](docs/how-to/troubleshooting.md)
for setup failures and the details to include in a bug report.

Report bugs and suggest features through [GitHub issues](https://github.com/mrogness/MimirOCR/issues).
Describe the expected behavior and provide reproduction steps, version/commit,
platform, and relevant error text.
